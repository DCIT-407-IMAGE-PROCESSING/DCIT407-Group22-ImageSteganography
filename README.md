# DCIT407-Group22-ImageSteganography

## Project Overview
Image steganography project for **DCIT 407** implementing a core embedding and extraction algorithm from first principles in **NumPy**, alongside a comparison against an alternative method or parameter setting.

## Repository Structure
- ``src/`` — First-principles steganography implementation, evaluation metrics, and comparison scripts.
- ``data/samples/`` — Small sample set of test images (full dataset linked below; large raw datasets are not pushed to Git).
- ``results/`` — Side-by-side comparison images, quantitative metric summaries, and comparison charts/tables.
- ``report/`` — Project report (8–15 pages including figures, PDF or Markdown).
- ``slides/`` — Presentation slides for the 10-minute presentation, 5-minute Q&A, and live demo.
